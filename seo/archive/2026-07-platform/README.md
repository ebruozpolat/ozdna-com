cost control, RAG reliability, tokenomics, and "alternative to LiteLLM / Portkey / OpenRouter /
Helicone". That narrative left public positioning on 8 July 2026. The pages it generated
(`/blog/`, `/compare/`, `/pillars/`, `/docs/`, `/sdk/`, `/pricing/` and the rest) now return
404 at the edge (see `netlify.toml`).

Kept only for history. **Do not run the generator** (`generate-ozdna-seo-phase2.mjs`): its paths
assume the old location, and it would regenerate pages that must stay offline.
