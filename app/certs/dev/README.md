# Local C2PA / dev signing material

Generated by `npm run certs:dev` (from `app/`).

Produces a self-signed ECDSA P-256 end-entity cert + PKCS#8 private key for local
signing experiments. Official C2PA Verify will show **"unknown source"** — that is
expected (hard rule 5). Never commit PEMs or keys; only this README is tracked.

| File | Purpose |
|------|---------|
| `signer.key.pem` | Private key (PKCS#8) |
| `signer.cert.pem` | Self-signed X.509 cert |
| `signer.pub.pem` | Public key (SPKI), optional convenience |

Regenerate: delete `*.pem` / `*.key` in this directory, then `npm run certs:dev`.
